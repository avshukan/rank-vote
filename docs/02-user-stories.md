# User Stories

## Create poll

- As a user, I want to create a poll with a question and options, so that I can gather opinions from a group.

- As a user, I want to get a shareable link, so that others can join the poll easily.

---

## Vote

- As a participant, I want to rank options using drag & drop, so that I can express my preferences clearly.

- As a participant, I want to vote without registration, so that I can join quickly.

---

## Results

- As a participant, I want to see the winning option, so that I know the group decision.

- As a participant, I want to see how scores were calculated, so that the result feels fair.

---

## Simplicity

- As a user, I want the app to be simple and fast, so that I don’t need instructions.
