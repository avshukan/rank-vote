# Product

## One-liner

A simple web app for group decisions using ranked voting

## Tagline

Rank options. Get better decisions.

---

## Users

- small groups (friends, colleagues, families)
- voting enthusiasts

---

## Use cases

- decide what to eat together
- plan a shared activity
- choose between multiple options
- resolve disagreements

---

## Problem

Simple polls:

- allow only one choice
- ignore preferences
- give poor results with 3+ options

---

## Solution

Ranked voting instead of single choice
