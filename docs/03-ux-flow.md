# UX Flow

## 1. Create poll

User opens the app

→ enters:
- question
- options (3–10)

→ clicks "Create"

→ gets a unique link

---

## 2. Share

User sends the link to others

---

## 3. Vote

Participant opens the link

→ sees question and options

→ ranks options using drag & drop

→ clicks "Submit"

---

## 4. Results

Participant sees:
- winner
- score table

---

## Notes

- no registration required
- voting is anonymous
- result is shown immediately after voting
